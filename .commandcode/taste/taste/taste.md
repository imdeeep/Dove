# Taste
- Prefers the assistant to fully explore and understand the codebase (across all relevant areas, e.g., app, docs, scripts, website) before starting discussion, design, or planning work. Confidence: 0.8
- When requesting a change, prefers the assistant to present a set of options/ideas (with a recommendation) rather than applying the change directly, then picks one by number. Confidence: 0.8
- Communicates in short, terse instructions and refers to previously presented options by number (e.g., "change it to 4") instead of restating the desired content. Confidence: 0.8
- Routes tasks to area-specific agents by mentioning them (e.g., "@website") so work is directed by domain. Confidence: 0.7
- Attaches screenshots as visual references when requesting UI changes, expecting the work to target the shown section. Confidence: 0.7
- Sets a high quality bar for UI work — explicitly asks for "10/10 UI" and expects materially richer, fully polished redesigns rather than minimal cosmetic tweaks. Confidence: 0.8
